# نماذج فواتير المنار الدولية — الأكواد

## محتوى المجلد
- `common.py`  : الثوابت (اللون البراندي #30246C، تضمين الشعار base64، CSS الأساسي).
- `data.py`    : بيانات الفاتورة النموذجية (العميل/المشروع/البنود/الإجماليات). عدّلها لتغذية القوالب.
- `d1.py`..`d5.py` : قالب لكل تصميم — كل ملف فيه دالة `html()` تُرجِع كود HTML كامل.
  - d1 = النسخة المطابقة 100% للأصل (أعمدة معكوسة كالأصل)
  - d2 = Modern Minimal
  - d3 = Boxed Sections
  - d4 = Contracting Grid (BOQ)  ← المرشّح لنظام ERP
  - d5 = Classic Letterhead-Light
- `render.py`  : يحوّل HTML ← PDF (weasyprint) ← PNG (pymupdf).
- `generate_all.py` : يولّد الخمسة دفعة واحدة.
- `setup_fonts.sh`  : يثبّت خط Tajawal وحِزم الرِندر (شغّله مرة واحدة).
- `logo_tight.png`  : الشعار المُقتطع من الفاتورة الأصلية (يستخدمه common.py).

## التشغيل
```bash
bash setup_fonts.sh            # مرة واحدة
python3 generate_all.py        # ينتج design1..5  بصيغتي PDF و PNG
```
