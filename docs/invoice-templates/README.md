# Invoice Template Reference Package

Design references for the manarERP invoice print system.

**Status:** Reference only — not connected to production.
**Future integration target:** `frontend/src/pages/InvoicePreview.tsx` (after approval)

---

## Five Available Designs

| File | Style |
|------|-------|
| `html/design1.html` | Classic — two-tone header, traditional Arabic layout |
| `html/design2.html` | Modern — clean lines, accent stripe |
| `html/design3.html` | Corporate — full-width header with logo |
| `html/design4.html` | Minimal — white space, subtle borders |
| `html/design5.html` | Bold — dark header, high-contrast typography |

---

## Fonts

Embedded Cairo (Google Fonts), offline-compatible.
No CDN dependency — all weights baked into the HTML as base64 data URIs.

Weights available: 400 · 600 · 700 · 800
Subsets: Arabic, Latin, Full

Source font files live in `source/fonts/` (woff2).

---

## Viewing the Templates

Open any `html/design*.html` directly in a browser — no server required.
All fonts, styles, and layout are self-contained.

---

## Source Files

| File | Purpose |
|------|---------|
| `source/common.py` | Shared rendering utilities |
| `source/data.py` | Sample invoice data for previews |
| `source/d1.py` – `d5.py` | Per-design HTML generators |
| `source/generate_all.py` | Batch renderer — generates all 5 |
| `source/render.py` | Single-design render entry point |
| `source/setup_fonts.sh` | Font download helper |
| `source/logo_tight.png` | Company logo (tight crop) |
| `source/logo_transparent.png` | Company logo (transparent BG) |
