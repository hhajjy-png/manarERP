⚠

حل مشكلة تشغيل البرنامج (Electron)

عند تنفيذ npm run dev لم تفتح نافذة البرنامج

سبب المشكلة

ظهرت الرسالة: Electron failed to install correctly

المعنى: حزمة Electron نُزّلت، لكن ملفها التنفيذي (الـ binary) لم يُنزَّل أثناء التثبيت — غالبًا بسبب الشبكة/جدار الحماية، أو لأن نسخة Node لديك حديثة جدًا (v26) بدل الموصى بها (Node 20 LTS). الكود سليم؛ المطلوب فقط إصلاح تثبيت Electron.

1

ثبّت Node 20 LTS بدل النسخة الحديثة

إلزامي
  1. افتح «إعدادات ويندوز» ← «التطبيقات» ← أزل النسخة الحالية من Node.js.
  2. اذهب إلى nodejs.org ونزّل الزر الأخضر LTS (ليس Current).
  3. ثبّته (Next … Install … Finish)، ثم تحقّق في PowerShell:
الخطوة 1: نزّل LTS (الأخضر) لا Current
node -v   # يجب أن يظهر v20.x.x
2

احذف مجلد Electron التالف وأعد تثبيته

إلزامي

افتح PowerShell داخل مجلد المشروع ونفّذ:

Remove-Item -Recurse -Force node_modules\electron
npm install electron@31.0.0 --save-dev
الخطوة 2: حذف Electron التالف ثم إعادة تنزيله
💡 راقب ظهور سطر Downloading electron… — هذا هو الملف التنفيذي الذي كان ناقصًا.
3

تأكّد أن Electron ثُبّت بنجاح

npx electron --version
الخطوة 3: ظهور رقم النسخة يعني النجاح
✅ إن ظهر v31.x.x فقد حُلّت المشكلة — انتقل للخطوة 4.
4

شغّل البرنامج

npm run dev

انتظر ٢٠–٤٠ ثانية، وستفتح نافذة البرنامج وتظهر شاشة الدخول:

الخطوة 4: شاشة الدخول — admin / Admin@123
⚠️ تذكّر تنفيذ db:migrate وdb:seed مسبقًا، وإلا لن تنجح عملية الدخول.
5

إذا فشل التنزيل (شبكة أو جدار حماية الشركة)

عند الحاجة فقط

إن أعاد الأمر نفس الخطأ، استخدم مرآة تنزيل بديلة ثم أعد المحاولة:

$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
Remove-Item -Recurse -Force node_modules\electron
npm install electron@31.0.0 --save-dev
npx electron --version
الخطوة 5: استخدام مرآة بديلة لتجاوز الحجب
💡 مرآة npmmirror غالبًا تتجاوز حجب جدار الحماية في الشبكات المؤسسية.

📋 ملخّص الأوامر (مرجع سريع)

node -v                                       # تأكد v20.x.x (LTS)
Remove-Item -Recurse -Force node_modules\electron
npm install electron@31.0.0 --save-dev
npx electron --version                        # يجب أن يظهر v31.x.x
npm run dev                                    # تشغيل البرنامج
