دليل تثبيت نظام المنار

نظام إدارة أعمال شركة المنار — تطبيق سطح مكتب لويندوز يعمل محليًا

1

تثبيت Node.js

مرة واحدة

البرنامج يحتاج بيئة تشغيل اسمها Node.js.

  1. افتح المتصفح واذهب إلى موقع nodejs.org
  2. اضغط الزر الأخضر الذي يحمل كلمة LTS (الإصدار المستقر) — سيُنزّل ملف بامتداد .msi
  3. شغّل الملف واضغط Next في كل الخطوات ثم Install ثم Finish
  4. للتأكد: افتح PowerShell (من زر ابدأ) واكتب:
الخطوة 1: صفحة nodejs.org — اضغط زر LTS الأخضر
node -v
💡 إذا ظهر رقم مثل v20.x.x فالتثبيت نجح. لو ظهر خطأ، أعد تشغيل الكمبيوتر وجرّب مجددًا.
2

فتح موجّه الأوامر داخل مجلد المشروع

  1. افتح مستكشف الملفات واذهب إلى مجلد المشروع:
C:\Users\hhajj\Claude\Projects\برنامج شركة المنار
  1. اضغط في شريط العنوان بالأعلى، امسح ما فيه، اكتب powershell ثم Enter
  2. ستفتح نافذة PowerShell داخل المجلد مباشرة
الخطوة 2: اكتب powershell في شريط عنوان المجلد
3

تثبيت مكتبات المشروع

يحتاج إنترنت

في نافذة PowerShell اكتب:

npm install
الخطوة 3: تثبيت المكتبات داخل PowerShell

سيبدأ بتنزيل المكتبات (٣–٧ دقائق أول مرة). انتظر حتى يعود سطر الأوامر جاهزًا.

💡 التحذيرات الصفراء (warnings) طبيعية وتُتجاهَل. المهم ألا يظهر error أحمر يوقف العملية.
4

تجهيز ملف الإعدادات

انسخ ملف الإعدادات النموذجي:

copy backend\.env.example backend\.env

(مُستحسن) افتح الملف backend\.env بالمفكرة وغيّر السطر JWT_SECRET إلى نص طويل عشوائي، ثم احفظ وأغلق.

5

إنشاء قاعدة البيانات

مرة واحدة

نفّذ الأوامر التالية واحدًا تلو الآخر:

# يجهّز أدوات قاعدة البيانات (يحتاج إنترنت أول مرة فقط)
npm run db:generate

# ينشئ الجداول — سيطلب اسمًا، اكتب: init
npm run db:migrate

# يُدخل الأدوار والصلاحيات والمستخدم الافتراضي
npm run db:seed
💡 بعد هذه الخطوة تصبح قاعدة البيانات جاهزة في backend\data\manar.db
6

تشغيل البرنامج

npm run dev

انتظر ٢٠–٤٠ ثانية، ثم تفتح نافذة البرنامج تلقائيًا وتظهر شاشة الدخول. سجّل الدخول بـ:

الخطوة 6: شاشة الدخول — admin / Admin@123
اسم المستخدم: admin  •  كلمة المرور: Admin@123
⚠️ لا تغلق نافذة PowerShell أثناء الاستخدام — هي التي تشغّل البرنامج. للإيقاف: أغلق نافذة البرنامج ثم اضغط Ctrl + C في PowerShell. وغيّر كلمة المرور الافتراضية فور أول دخول.
7

(اختياري) إنشاء مُثبّت فعلي بأيقونة على سطح المكتب

بعد الخطوة 5، نفّذ:

npm run dist

بعد انتهائه، اذهب إلى مجلد release وستجد ملف التثبيت:

release\ManarSetup-1.0.0.exe
الخطوة 7: ملف المثبّت واختصار سطح المكتب بعد التثبيت

شغّله واتبع خطوات التثبيت، وسيظهر اختصار «نظام المنار» على سطح المكتب. بعدها يفتح البرنامج بنقرة مزدوجة كأي برنامج عادي، ويحفظ بياناته على جهازك تلقائيًا.

📋 ملخّص الأوامر (مرجع سريع)

أول مرة فقط:

npm install
copy backend\.env.example backend\.env
npm run db:generate
npm run db:migrate      # اكتب: init
npm run db:seed

كل مرة بعد ذلك للتشغيل:

npm run dev
⚠️ الخطوات التي تحتاج إنترنت هي npm install وnpm run db:generate فقط (أول مرة). بعدها يعمل البرنامج دون إنترنت نهائيًا.
