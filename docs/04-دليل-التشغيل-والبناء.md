# دليل التشغيل وبناء المثبّت — خطوة بخطوة

نظام إدارة أعمال شركة المنار (الكويت) — تطبيق سطح مكتب لويندوز يعمل بالكامل محليًا.

---

## 1. المتطلبات (مرة واحدة)

1. **Node.js 20 LTS أو أحدث** — حمّله من <https://nodejs.org> وثبّته (يتضمن npm).
   للتأكد بعد التثبيت، افتح موجّه الأوامر (PowerShell) واكتب:
   ```bash
   node -v
   npm -v
   ```
2. **Git** (اختياري) — لإدارة الإصدارات.

> ملاحظة: لا حاجة لأي خادم أو إنترنت لتشغيل البرنامج بعد التثبيت — كل شيء محلي.

---

## 2. تثبيت المشروع

افتح PowerShell داخل مجلد المشروع:

```powershell
cd "C:\Users\hhajj\Claude\Projects\برنامج شركة المنار"
npm install
```

هذا يثبّت اعتماديات الجذر + الواجهة (frontend) + الخلفية (backend) دفعة واحدة (workspaces). قد يستغرق بضع دقائق أول مرة.

---

## 3. تهيئة قاعدة البيانات (مرة واحدة)

```powershell
# 1) جهّز ملف البيئة للخلفية
copy backend\.env.example backend\.env
#    افتح backend\.env وغيّر JWT_SECRET إلى قيمة عشوائية طويلة

# 2) ولّد Prisma Client
npm run db:generate

# 3) أنشئ قاعدة البيانات والجداول
npm run db:migrate
#    سيطلب اسم الترحيل — اكتب: init

# 4) املأ البيانات الأولية (الأدوار + الصلاحيات + المدير الافتراضي + إعدادات الشركة)
npm run db:seed
```

ينشئ ذلك ملف قاعدة البيانات في `backend\data\manar.db` مع:
- الأدوار السبعة وصلاحياتها.
- مستخدم مدير النظام: **admin / Admin@123** (غيّر كلمة المرور فور أول دخول).
- إعدادات الشركة (العملة دينار كويتي، بلا نظام ضريبي).

---

## 4. تشغيل التطبيق (وضع التطوير)

```powershell
npm run dev
```

سيحدث التالي تلقائيًا:
1. تعمل واجهة Vite على المنفذ 5173.
2. يفتح Electron نافذة التطبيق ويشغّل الخدمة الخلفية داخليًا على `127.0.0.1:48211`.
3. تظهر شاشة الدخول → ادخل بـ **admin / Admin@123**.

تتنقّل بين الوحدات من القائمة الجانبية: لوحة التحكم · العقود · العملاء · المعدات · الموظفون · الفواتير · المصروفات · الموردون · القيود المحاسبية · التقارير · المستخدمون · النسخ الاحتياطي · الإعدادات.

> النسخ الاحتياطي التلقائي يعمل يوميًا 2:00 صباحًا (توقيت الكويت)، ويُحفظ في `backend\data\backups`.

---

## 5. بناء مُثبّت ويندوز (.exe)

> مهم: تأكّد أنك نفّذت الخطوة 3 (migrate + seed) أولًا، لأن المثبّت يرفق قاعدة بيانات مبدئية مُهيّأة من `backend\data\manar.db`.

```powershell
npm run dist
```

يقوم الأمر بـ:
1. بناء الخلفية (`backend\dist`).
2. بناء الواجهة (`frontend\dist`).
3. ترجمة كود Electron (`electron-dist`).
4. إنتاج المثبّت عبر electron-builder.

**الناتج:** `release\ManarSetup-1.0.0.exe`

ثبّته كأي برنامج ويندوز (يدعم اختيار مجلد التثبيت، ويُنشئ اختصار سطح المكتب وقائمة ابدأ بالعربية).

### ماذا يحدث عند أول تشغيل بعد التثبيت؟
- يُنشئ التطبيق مجلد بياناته في:
  `C:\Users\<اسمك>\AppData\Roaming\نظام المنار\data\`
- ينسخ قاعدة البيانات المبدئية المُهيّأة إلى هناك (فلا تبدأ فارغة).
- كل البيانات والنُّسخ والسجلّات تُحفظ في هذا المجلد، ويبقى مستقلًا عن أي تحديث للتطبيق.

---

## 6. النسخ الاحتياطي والاستعادة

- **يدوي:** من صفحة «النسخ الاحتياطي» → زر «نسخة احتياطية الآن».
- **تصدير:** يحفظ نسخة في مكان تختاره على جهازك.
- **استعادة:** اختر نسخة → «استعادة» → يُعاد تشغيل التطبيق تلقائيًا على البيانات المستعادة (مع أخذ نسخة أمان قبلها).

---

## 7. حل المشكلات الشائعة

| المشكلة | الحل |
|--------|------|
| `prisma generate` يفشل بخطأ شبكة | تأكّد من الاتصال أول مرة فقط (لتنزيل محرّك Prisma)، ثم يعمل دون إنترنت. |
| النافذة تفتح بيضاء | انتظر ثوانٍ (الخدمة الخلفية تُقلع)، أو أعد التشغيل. تحقّق أن المنفذ 48211 غير مستخدم. |
| «اسم المستخدم أو كلمة المرور غير صحيحة» | تأكّد أنك نفّذت `npm run db:seed`. الافتراضي admin / Admin@123. |
| المثبّت يفشل عند `from: backend/data/manar.db` | نفّذ migrate + seed قبل `npm run dist` لإنشاء قاعدة البيانات المبدئية. |
| تعديلات على الحقول لا تظهر | بعد أي تغيير في `schema.prisma`، نفّذ `npm run db:migrate` ثم أعد التشغيل. |

## 8. ملاحظات حول نموذج البيانات الحالي

- **العقود** (بدل المشاريع): رقم العقد، مصنع الأسفلت، مكان العقد، قيمة النقل الشهري، الحالة.
- **المعدات/المركبات**: رقم المعدة، النوع، اسم المالك، اسم السائق، رقم اللوحة، تاريخ انتهاء دفتر المركبة (مع تنبيه قبل 30 يومًا)، الحالة (تعمل/لا تعمل).
- **الموظفون**: الاسم عربي/إنجليزي، الرقم المدني، المهنة، الجنسية، الجواز وانتهاؤه، الإقامة وانتهاؤها، الرخصة وانتهاؤها، الميلاد، الشركة، العنوان، الراتب الشهري، الحالة (مع تنبيه انتهاء المستندات قبل 30 يومًا).
- العملة: **دينار كويتي (د.ك)** — لا يوجد نظام ضريبي.
