# سياق المشروع للمتابعة (Handoff) — نظام إدارة أعمال شركة المنار

> هذه الوثيقة تُعطى لأي مساعد ذكاء اصطناعي (مثل Google Gemini) ليكمل العمل من حيث توقّفنا. اقرأها أولًا، ثم اقرأ `README.md` ووثائق `docs/`.

## 1. ما هو المشروع
تطبيق سطح مكتب لويندوز يعمل **محليًا بالكامل (Offline)** لإدارة أعمال شركة مقاولات طرق (نقل أسفلت) في **الكويت**. العملة **دينار كويتي (KWD)** و**لا يوجد نظام ضريبي**.

## 2. المجموعة التقنية (Stack)
- **الخلفية:** Node.js + Express + TypeScript + Prisma ORM + SQLite. (مجلد `backend/`)
- **الواجهة:** React 18 + TypeScript + Vite + Zustand + Chart.js. (مجلد `frontend/`)
- **سطح المكتب:** Electron (يشغّل الخلفية داخليًا). (مجلد `electron/`)
- **المثبّت:** electron-builder (`electron-builder.yml`).
- المعمارية: Clean Architecture + Repository Pattern + RBAC. التفاصيل في `docs/01-معمارية-النظام.md`.

## 3. كيف يُشغَّل (مرجع سريع)
```bash
# أول مرة
npm install
cd backend && copy .env.example .env
npm run prisma:generate && npm run prisma:migrate && npm run prisma:seed && cd ..
# التشغيل
npm run dev          # يفتح نافذة التطبيق (admin / Admin@123)
# المثبّت
npm run dist         # ينتج release\ManarSetup-1.0.0.exe
```

## 4. ما أُنجز بالكامل
- **الخلفية (17 وحدة):** المصادقة، المستخدمون والأدوار (RBAC 7 أدوار)، العملاء، **العقود** (نقل أسفلت: رقم العقد/مصنع الأسفلت/المكان/قيمة النقل الشهري)، **المعدّات** (رقم/نوع/مالك/سائق/لوحة/انتهاء دفتر المركبة + تنبيه 30 يوم/الحالة تعمل-لا تعمل)، الصيانة، **الموظفون** (اسم عربي/إنجليزي، الرقم المدني، المهنة، الجنسية، الجواز+انتهاؤه، الإقامة+انتهاؤها، رخصة القيادة، رخصة المركبة، لوحة المركبة، الميلاد، الشركة، العنوان، الراتب، الحالة + تنبيهات انتهاء المستندات)، الفواتير (بنود/دفعات/قيد محاسبي)، المصروفات (اعتماد)، الموردون، القيود المحاسبية، **الرواتب** (`SalaryPayment` + ملخص شهري محسوب)، لوحة التحكم، التقارير، النسخ الاحتياطي، الإعدادات، سجل التدقيق.
- **الواجهة:** صفحات لكل ما سبق + لوحة تحكم بالرسوم + صفحة رواتب بفلتر باسم الموظف + صفحة طباعة تقارير بعربية سليمة (`/print/:type`).
- **أدوات استيراد Excel** (مجلد `backend/scripts/`): عامة مدفوعة بإعدادات `import-config.ts`، تدعم: `employees`, `equipment`, `contracts`, `customers`, `salaries`. تكتشف ورقة العمل وصف العناوين تلقائيًا. الأمر: `npm run import -- <الوحدة> "ملف.xlsx"` والقوالب: `npm run template`.
- **بيانات حقيقية مُستوردة:** 26 موظفًا + 212 عملية رواتب (من ملفات المستخدم).

## 5. اصطلاحات مهمة يجب اتباعها
- **بنية كل وحدة خلفية:** مجلد تحت `backend/src/modules/<name>/` فيه: `*.routes.ts` (مسارات) → `*.controller.ts` → `*.service.ts` (منطق الأعمال) → `*.repository.ts` (Prisma) → `*.schema.ts` (تحقق Zod). تُسجَّل الراوترات في `backend/src/app.ts`.
- **الصلاحيات:** كل مسار محمي بـ `authenticate` + `requirePermission('module.action')`. مدير النظام يتجاوز كل الفحوص.
- **الواجهة مدفوعة بإعدادات:** معظم الصفحات تُعرَّف في `frontend/src/config/modules.tsx` (أعمدة الجدول + حقول النموذج) وتُعرض عبر `frontend/src/pages/ResourcePage.tsx`. الصفحات الخاصة (Dashboard, Invoices, Salaries, Accounting, Reports, Settings, Backup) منفصلة.
- **القائمة الجانبية والراوتر:** تُضاف الوحدة في `NAV` داخل `modules.tsx` + مسار في `frontend/src/App.tsx`.
- **عميل الـ API:** `frontend/src/api/client.ts` (Axios، يضيف رمز الجلسة). الاستجابات بصيغة `{ success, data }`؛ القوائم `{ data: { data:[], meta:{} } }`.
- **العملة:** دالة `money()` في `modules.tsx` (KWD، حتى 3 خانات). لا ضريبة (taxRate=0 دائمًا).
- **PDF العربي:** لا تستخدم مولّد PDFKit للعربية (يكسر الحروف). استخدم صفحة الطباعة `/print/:type` (Chromium) أو تصدير Excel.
- **بعد أي تعديل في `schema.prisma`:** نفّذ `npx prisma migrate dev --name <اسم>` ثم `npx prisma generate` من `backend/`.

## 6. مهمة قيد التنفيذ (لم تكتمل) — تخصيص الفاتورة لنقل الأسفلت
المطلوب من المستخدم: في نافذة «فاتورة جديدة»:
1. إضافة **نوع الخدمة** للفاتورة بقيم: «نقل اسفلت»، «يومية عمل مالينج»، «يومية نقل اسفلت».
2. إضافة **وحدة الكمية** لكل بند بقيم: «طن»، «درب»، «يومية».
3. إبقاء **السعر** مع حساب الإجمالي تلقائيًا (الكمية × السعر).

**الخطوات المتبقية لإكمالها:**
- `backend/prisma/schema.prisma`: أضف `serviceType String?` إلى موديل `Invoice`، و`unit String?` إلى موديل `InvoiceItem`. ثم migration.
- `backend/src/modules/invoices/invoices.schema.ts`: أضف `serviceType` (اختياري) لمخطط الإنشاء/التعديل، و`unit` (اختياري) لمخطط البند `itemSchema`.
- `backend/src/modules/invoices/invoices.service.ts`: خزّن `serviceType` على الفاتورة و`unit` على البنود (في `computeTotals`/`create`/`update`).
- `frontend/src/pages/Invoices.tsx` (مكوّن `CreateInvoice`): أضف قائمة «نوع الخدمة» (القيم الثلاث)، وقائمة «الوحدة» بجانب كل بند (طن/درب/يومية)، وأرسلها في `POST /invoices`. اعرض القيم في قائمة/تفاصيل الفاتورة.

> القيم تُخزَّن كنص عربي مباشرة (لا حاجة لـ enums).

## 7. مهام مقترحة لاحقة
- استيراد المعدّات/العقود/العملاء (الأدوات جاهزة، فقط تشغيل الأوامر بملفات المستخدم).
- ربط صفحة الرواتب باستيراد دوري بدل الثابت (جاهزة فعليًا).
- طباعة الفاتورة كـ PDF عبر صفحة طباعة مخصّصة (مثل `/print/:type`).
- تحسينات تقارير لكل وحدة.

## 8. ملاحظات تشغيلية من تجربة المستخدم
- مكافح الفيروسات لديه **McAfee** كان يحذف `electron.exe`؛ الحل: استثناء مجلد المشروع في McAfee أو إيقاف الفحص الحقيقي عند تثبيت Electron، واستخدام مرآة التنزيل `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`.
- نسخة Node لدى المستخدم حديثة (v24)؛ يُفضّل Node 20 LTS.
- ملفات Excel قد تحتوي صف عنوان كبير وأوراق متعددة — أدوات الاستيراد تتعامل مع ذلك تلقائيًا.
