# اتجاه الطباعة الحالي — Universal Print Preview v1

> **الحالة:** قيد التطوير — لم يُدمج ولم يُوسم. الأعلام كلها **OFF**.
> يحلّ هذا المستند محل خطة «Print Center الكامل» بوصفه الاتجاه المعتمد.

---

## القرار

**Print Center الكامل مؤجَّل.** الهدف الحالي أضيق وأكثر أمانًا:

> نافذة معاينة موحّدة قبل الطباعة لأي مستند، **مع إبقاء مسار الطباعة القديم المستقر لكل صفحة كما هو**.

**المعاينة تعرض فقط. المعاينة لا تطبع.**

```
printable root الحالي
  → compose (نفس القالب، نفس الـ CSS، بلا إعادة رسم)
  → عرض داخل iframe في نفس أصل التطبيق
  → يراجع المستخدم
  → يضغط «طباعة»
  → تُغلق المعاينة ثم يُستدعى مسار الطباعة القديم للصفحة (callback)
```

## خارج النطاق (لا يُنفَّذ الآن)

- Print Queue · Batch Printing · Archive
- **Artifact-based physical printing** (طباعة نفس بايتات الـ PDF)
- **Hidden BrowserWindow** لطباعة PDF · **`plugins:true`**
- فرض أن preview/save/print تستخدم نفس الـ PDF
- إعادة بناء محرك الطباعة
- **ترحيل الشيكات** — الشيكات غير متأثرة إطلاقًا
- تغيير أي مسار طباعة فعلي مستقر
- PDFKit retirement · Reports · Payroll · Executive

## لماذا تراجعنا عن مسار الـ PDF artifact؟

الاختبار اليدوي أثبت عطلين حاسمين:

1. **العربية مشوّهة في المعاينة.** المعاينة كانت تكتب المستند إلى **ملف مؤقّت** وتحمّله في نافذة مخفية عبر `file://`. أصل التطبيق في التطوير هو `http://localhost`، فلم تستطع نافذة `file://` تحميل خطوطه (cross-origin) — سقطت كل الخطوط، وعاد Chromium إلى خط نظام لا يشكّل العربية ولا يصلها.
2. **الطباعة الفعلية أخرجت ورقة بيضاء** عبر تحميل PDF في نافذة مخفية بـ `plugins:true`.

**الحل ليس ترقيع الخطوط، بل عدم الخروج من أصل التطبيق أصلًا:** المعاينة الآن `<iframe srcdoc>` داخل نفس المستند — نفس الأصل، والخطوط محمّلة فعلًا، فالعربية تظهر مشكّلة ومتّصلة والشعار والصور تظهر.

## الأعلام — كلها OFF

```
PRINT_CENTER_PHASE2            (master kill switch)
PRINT_CENTER_PHASE2_INVOICE    = false   ← الطيّار
PRINT_CENTER_PHASE2_QUOTATION  = false   ← لا يُفعَّل قبل نجاح الفاتورة يدويًا
```

الأسماء لم تُغيَّر عمدًا — تغييرها بلا migration يفقد أي تجاوز محفوظ في `localStorage`.
الرجوع فوري بلا إعادة بناء: `localStorage['manar:flag:PRINT_CENTER_PHASE2'] = 'off'`.

## قاعدة زر الطباعة

نافذة المعاينة **presentation-oriented**: لا تعرف IPC، ولا تطبع.
زر «طباعة» بداخلها:

1. يغلق المعاينة (وإلا ظهرت في الورقة — مسار الطباعة القديم يطبع النافذة المرئية).
2. يستدعي `onPrint()` — callback تملكه الصفحة وتنفّذ فيه مسارها القديم.
3. يمنع النقر المزدوج.

**لا `webContents.print` على نافذة المعاينة. لا طباعة لنافذة التطبيق من داخلها.**
